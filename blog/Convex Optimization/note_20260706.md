# Abstruct
(Affine/Convex/Convex Cone) $\times$ (set/combination/hull)

cone, convex cone


# Affine set/Affine combination/Affine hull
## 仿射集
C is an affine set, iff
$$
\forall x_1, \cdots, x_k \in C, \forall \theta_1, \cdots, \theta_k \in \mathbb{R}, \sum_{i=1}^{k} c_i\theta_i \in C, s.t. \sum_{i=1}^k\theta_i = 1
$$
## 仿射组合
The affine combination of $x_1, \cdots, x_k$ is:
$$
\sum_{i=1}^k \theta_ix_i| \sum_{i=1}^k\theta_i = 1, \theta_i \in \mathbb{R}\forall i 
$$
## 仿射包
The affine hull of $C$ is denoted as **conv** $C$, which is defined as:
$$
\mathrm{aff} C = \left\{\sum_{i=1}^k \theta_ix_i| \sum_{i=1}^k\theta_i = 1, \theta_i \in \mathbb{R},x_i\in C \forall i\right\}
$$
)

# Convex set/Convex combination/Convex hull
## 凸集
C is a convex set, iff
$$
\forall x_1, \cdots, x_k \in C, \forall \theta_1, \cdots, \theta_k \in \mathbb{R}, \sum_{i=1}^{k} c_i\theta_i \in C, s.t. \sum_{i=1}^k\theta_i = 1, \theta_i \in [0,1] \forall i
$$
## 凸组合
The convex combination of $x_1, \cdots, x_k$ is:
$$
\sum_{i=1}^k \theta_ix_i| \sum_{i=1}^k\theta_i = 1, \theta_i \in [0,1]\forall i 
$$
## 凸包
The convex hull of $C$ is denoted as **conv** $C$, which is defined as:
$$
\mathrm{conv} C = \left\{\sum_{i=1}^k \theta_ix_i| \sum_{i=1}^k\theta_i = 1, \theta_i \in [0,1],x_i\in C \forall i\right\}
$$
)

# Cone(Nonnegative homogeneous)
C is a cone, iff

$$
\forall x\in C, \theta x \in C, \forall \theta \geq 0
$$


# Convex cone/Conic combination(Nonnegative linear combination)/Conic hull
## 凸锥
C is a convex cone, iff
$$
\forall x_1, \cdots, x_k \in C, \forall \theta_1, \cdots, \theta_k \in \mathbb{R}, \sum_{i=1}^{k} c_i\theta_i \in C, s.t. \theta_i \geq 0 \forall i
$$
## 凸锥组合
The conic combination of $x_1, \cdots, x_k$ is:
$$
\sum_{i=1}^k \theta_ix_i| \theta_i \geq 0 \forall i 
$$
## 凸锥包
The conic hull of $C$ is:
$$
\left\{\sum_{i=1}^k \theta_ix_i| \theta_i \geq 0,x_i\in C \forall i\right\}
$$

# Tips 

只有一个点的集合是仿射集、凸集，只有当这个点在原点时是凸锥。
空集是仿射集、凸集和凸锥。
