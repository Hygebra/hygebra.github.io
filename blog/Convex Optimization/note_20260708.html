Abstruct

The first part is some important convex sets.

The second part is some operations that preserve convexity.

Hyperplane

A hyperplane is a set of the form \[ \left\{{x|a^Tx=b}\right\}, a\in \mathbb{R}^n, a\neq 0, b \in \mathbb{R} \]

Halfspace

A hyperplane divides a space into two halfspaces. A half space is a set of the form \[ \left\{{x|a^Tx\leq b}\right\}, a\in \mathbb{R}^n, a\neq 0, b \in \mathbb{R} \] A halfspace if convex but not affine.

Euclidean ball and ellipsoids

Ball

A ball in \(\mathbb{R}^n\) is a set of the form \[ B(x_c, r) = \left\{x| \parallel x - x_c\parallel \leq r \right\} \] A ball is a convex set. The proof needs triangular inequality. ## Ellipsoid Ellipsoid is also a convex set of the form \[ \left\{x| (x-x_c)^TP^{-1}(x-x_c)\leq 1 \right\}, P=P^T\succ 0 \] The lengths of the semi-axes of \(P\) are given by \(\sqrt{\lambda_i}\), where \(\lambda_i\) are the eigenvalues of \(P\). A ball is an ellipsoid with \(P = r^2I\).

Polyhedra

A polyhedron is defined as the solution set of a finite number of linear equalities and inequalities: \[ P = \left\{x|a_i^Tx\leq b_i, i = 1, \cdots, m, c^T_jx=d_j,j=1, \cdots, p\right\} \]

Simplex

Simplexes are another important family of polyhedra. Suppose the \(k + 1\) points \(v_0,\cdots, v_k \in \mathbb{R}^n\) are affinely independent, which means \(v_1-v_0,\cdots,v_k-v_0\) are linearly independent. The simplex determined by them is given by \[ C = \text{conv} \left\{v_0, v_1, \cdots, v_k\right\} = \left\{x| x=\theta^Tv, 1^T\theta=1, \theta \succeq 0\right\}\ \]

Theo. A simplex is a polyhedron.

Proof. For a simplex \(S\), there exist \(k+1\) points \(v_0,\cdots, v_k \in \mathbb{R}^n\) are affinely independent.

\(v_1-v_0,\cdots, v_k-v_0 \in \mathbb{R}^n\) is denoted by \(B\), and \(\theta_1,\cdots, \theta_k\) is denoted by \(A\).

Thus, \(\forall x \in S\), we have \[ \begin{split} x &= \theta^Tv \\ &= v_0 + \theta_1(v_1 - v_0) + \cdots + \theta_k(v_k - v_0) \\ &= v_0 + BA \end{split} \] For column linear independent matrix \(B_{n\times k}\), there exist a inversive matrix \(P_{n\times n}\) such that \(PB = \begin{bmatrix} I_k \\ 0\end{bmatrix}\). Therefore, we have \[ \begin{split} Px &= Pv_0 + PBA\\ &= Pv_0 + \begin{bmatrix} A\\ 0 \end{bmatrix} \end{split} \] Therefore, \[ P_1x=P_1v_0 + A\\ P_2x=P_2v_0 \] The \(\theta_i(i=1, \cdots, k)\) vary, we can vary all the values satisfy \(A \geq 0, 1^TA \leq 1\). So we finally get \[ P_1x\geq P_1v_0\\ 1^TP_1x \leq 1^TP_1v_0 + 1\\ P_2x = P_2v_0 \] And the reasoning is bidirectional.
